# Журнал рішень

Формат: розвилка → варіанти → рішення → чому. Факти, на які спираються рішення, перевірено живими запитами до API 2026-09-27.

| # | Розвилка | Варіанти | Рішення | Чому |
|---|---|---|---|---|
| 1 | Розподіл ролей | агент пише код / агент оркеструє детермінований код | **LLM вирішує, що міряти, і пояснює; код міряє** | Дешева модель надійно розуміє запит, але помиляється в арифметиці й у написанні коду з нуля. Умова вимагає власного коду навички |
| 2 | Гранулярність інтерфейсу | одна команда «зроби все» / жорсткий конвеєр / набір примітивів | **5 незалежних команд** (`find`, `analyze`, `views`, `top`, `report`) + типовий рецепт | Питання можуть бути будь-якими: жорсткий конвеєр їх не вміщує, а дрібні інструменти змушують Haiku їх компонувати і помилятися |
| 3 | Одиниця «теми» | одна стаття / набір елементів Wikidata / категорія / `articletopic` | **Набір QID і конкретних статей + редиректи** | Крос-мовна прив'язка через Wikidata. Категорії відрізняються між мовами і розростаються. `articletopic` лишаємо на roadmap |
| 4 | Головна метрика зростання | «початок проти кінця» / нахил тренду / р/р | **Відносний р/р** (частка розділу, останні 12 міс. проти попередніх 12) | Нейтральний до сезонності, зрозумілий фаундеру. Людських переглядів Вікіпедії у 2025 стало на ~8% менше, тому сирі перегляди змішують інтерес до теми з падінням платформи. Сирий р/р показується поруч |
| 5 | Невизначеність | p-values / бутстреп / байєсівська модель | **Парний бутстреп по календарних місяцях** | Зберігає сезонність, простий, дає інтервал, зрозумілий нетехнічному читачу |
| 6 | Модель довіри | зведений скор / прозорий чекліст | **Правила: напрям + High/Medium/Low + причини** | Кожне зниження довіри пояснюване; «скор 0.73» не пояснити і не перевірити |
| 7 | Перевірка висновків | нічого / статистичний тест / аналіз чутливості | **Чутливість**: без сплесків, вікно на 6 міс. раніше, без редиректів; стабільність лідера в порівняннях | Відповідає на «наскільки довіряти» мовою рішень: «висновок тримається в N з M варіантів» |
| 8 | Нулі та 404 | довіряти відповіді API / перевіряти окремо | **Заповнювати нулями; існування сторінки перевіряти окремо** | API пропускає дні з нулем (60 днів → 6 записів); 404 однаковий для «статті немає» і «переглядів немає» |
| 9 | Редиректи | ігнорувати / включати | **Включати** (до 30 на статтю, за переглядами за 60 днів) | Частина інтересу і стара історія після перейменувань живуть на редиректах (у «Intermittent fasting» в enwiki ~25 редиректів) |
| 10 | Відсутня стаття | помилка / мовчки підставити проксі / явно сказати | **Явно «не вимірюється» + кандидати з локального пошуку** | Статті про intermittent fasting немає в plwiki — це клас ситуацій, а не виняток; проксі обирає агент і маркує |
| 11 | Ліміти Wikimedia | ігнорувати / коректний User-Agent + обмеження частоти + кеш | **UA з контактом із `WIKI_CONTACT`, ≤ 3 паралельних, повтори з `Retry-After`, SQLite-кеш** | Без контакту ліміт — 10 запитів/хв (отримали 429); з контактом 15 запитів поспіль — без 429 |
| 12 | Кеш і стан | без кешу / файли / SQLite | **SQLite, дозавантаження лише відсутніх діапазонів** | Повторні й пов'язані запити не звертаються до API вдруге; кілька процесів evals ділять один кеш |
| 13 | Хто пише звіт | шаблон у коді / LLM вільно / гібрид | **Гібрид**: числа, таблиці й графіки генерує код; LLM пише короткі нотатки, а код перевіряє в них числа | Гнучкість тексту без вигаданих чисел |
| 14 | Рушій PDF | WeasyPrint / Chrome / Typst / reportlab / fpdf2 | **fpdf2 + matplotlib, шрифт DejaVu з matplotlib** | Pure-Python, без системних залежностей. Перевірено: 1 сторінка, кирилиця і діакритика коректні |
| 15 | Пакування | pip + requirements / pyproject / PEP 723 | **PEP 723 + lock-файл, запуск `uv run`** + `requirements.txt` як запасний варіант | Одна команда з будь-якої директорії; перший запуск ~6 с, далі миттєво |
| 16 | Мова | — | SKILL.md і код — англійською; відповіді й PDF — мовою користувача (мітки en/uk); документація для рецензентів — українською | Слідування інструкціям і переносимість між агентами; аудиторія рецензентів |
| 17 | Питати чи діяти | питати завжди / діяти з дефолтами | **Діяти з названими дефолтами**; питати лише при реальній неоднозначності або «наших мовах» без переліку | Фаундеру потрібна швидка відповідь, а уточнення підтримуються |
| 18 | Evals | 3 приклади / великий набір | **Таксономія → робочий набір (окремий агент) + прихований набір (окремий агент без таксономії, поза репо)** | Питання можуть бути будь-якими; перевірки не мають бути заточені під приклади |
| 19 | Середовище evals | Claude Code з усіма налаштуваннями / ізольоване | **`claude -p --model haiku --setting-sources project`** | Без ізоляції вкладений прогін бачить ~90 сторонніх навичок; ізоляція робить результати відтворюваними |
| 20 | Приватність контакту | email у коді / у змінній середовища | **Лише `WIKI_CONTACT`**, ніколи не друкується; локальні git-хуки блокують витік, коміти підписані noreply-адресою | Email не має з'являтися ні в репозиторії, ні в історії комітів |
